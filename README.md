# Strata

Strata is a multi-organization change-operations console for teams coordinating production releases. It combines change requests, approvals, service ownership, audit activity, saved views, and background synchronization in one React application.

## Run locally

```bash
pnpm install
pnpm dev
```

## Verify

```bash
pnpm test
pnpm build
```

The application uses a deterministic in-memory backend and requires no external credentials.
